# Example creative note: ARGUS

This is a thinking pattern. It is not a shot list to reuse, and it is not permission to invent Argus UI.

```
INTENT: A launch film for people who run multi-agent pipelines. Plays as a product video. After it, they should believe a healthy-looking run can hide a failure, and that Argus can show it and fix it.
JOB: Launch film
FORMAT: 30s / 16:9 / 30fps / music, mute-safe
THESIS: This film makes the viewer understand that an agent run can look healthy while something failed, and that Argus makes that failure traceable and fixable.
REAL: Execution trace, the retrieve → rerank → answer path if those states exist, replay or diagnosis UI, the Argus name and brand colors. No invented metrics.
BEATS: ideas only. A real note adds a frame range, a role, a curve, and what carries. Do not reuse these lines on another product.
1. A run that looks successful.
2. One node goes wrong. Everything else stays calm.
3. The trace opens and becomes the hero, large enough to read.
4. The failing node is isolated. The cause is named in the real UI.
5. The same path resolves after the fix.
6. Argus, plus one line of promise.
EXCLUDE: Full dashboard, cyberpunk HUD, particle "AI", orange fog, a card per feature, logo-first opening, ending on the renderer.
SYSTEM: Ground from the real brand (ink if that is what Argus is). One accent for the anomaly, used semantically. Type from the product. Motif: a single trace line. Continuity object: that line, from overview to node to resolved run. Easing: arrive-and-settle for UI, linear only for the trace drawing on.
BORROW: One proof at a time. Hard cuts between states. A hold on the claim. Brand smaller than the idea.
WILL NOT COPY: Any reference film's layout, palette, sentences, or end card. No "model logo" close.
HERO STILL: The failing node, isolated, with the cause readable and the rest of the trace quiet.
```

## Why this shape

The interesting fact is the silent failure, not the existence of a dashboard. The trace is the picture of that fact. The real UI appears where it proves the diagnosis. The fix is a before/after on the same path, so the viewer sees the product work.

Rejected on sight: black field, colored blob, centered card, blur, another card, logo.
