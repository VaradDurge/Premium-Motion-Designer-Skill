# Reference pack

Credits. Do not load this file to design a film. It is not a shot list, a palette, or an input to the creative note.

The skill was built from **15 references**, watched for grammar. Do not reproduce their copy, layouts, products, or end cards.

Principles live in [reference-grammar.md](reference-grammar.md). Motion timing lives in [motion-craft.md](motion-craft.md).

## The 15

Posts:

1. https://x.com/0xCrosss/status/2104820640222155173 — a product film is real UI states and quiet lines. Remaking someone else's film, then ending on the tool that rendered it, is the failure this skill exists to prevent.
2. https://x.com/uxmiles/status/2104618175803609305 — one accent, a cursor with a job, type as an object, one continuity dot, empty frames, a designed lockup.
3. https://x.com/ArchiveExplorer/status/2105023417716191488 — brand facts first, stills before motion, a review pass with specific notes. Centered type, a soft gradient, and fade-everything is the default to beat.
4. https://x.com/jashandotsol/status/2104693955950449005 — "go all out" without a system becomes a catalog. Invented metrics are not proof.

Revid wall, films that changed a rule:

5. @stephanlivera — the 15s showreel. A persistent stage, one poster per cut, flat color as the transition, lockup at the end.
6. @donaldjewkes — the illustrated timeline. A long film works when every scene is a new beat in the same material.
7. @shneural — loud type inside a repeated poster grid. The object stays in its slot.
8. @ajith_io — "every frame." A motif used as a system, then a quiet wordmark.
9. @deedydas — muda. The product-film shape: action, problem, one number, mechanism, sentence, brand last.
10. @twoclipping — Develop. UI at readable size, a cursor that completes an action, then the consequence outside the interface, then the wordmark.
11. @himanshutwtxs — animation principles, demonstrated. Stretch, snap, slow-in and slow-out, arcs. The curve on screen has to be the curve in the move.
12. @DanielSmidstrup — ClimbX. A question, one changing number, one phrase with a single accent word. The logo hold at the end is too long. Do not copy that part.
13. @darel023 — Timing. One accent on ink, a chart of the move, then the move. Precision over decoration.
14. @shownotover — XFastest. A sentence, then the UI that proves it, then the next sentence. Paper ground, one accent.
15. @Heykazitarek — the Gamma walkthrough. A screen recording of generation is a process clip, not a launch film. Do not ship the editor as the ad unless the editor is the product.

## Also watched, not separate styles

These were reviewed and folded in only as cautions. They do not add another look:

- @rexan_wong — a short process clip of many videos. Not a visual style.
- @brivael — a long essay. Useful only for the lesson that one material can hold many claims.
- @higgsfield_ai — a making-of inside a jungle plate. Process footage, plus a sticker, is not a brand film.
- @kaolti — a robot head in a 3D viewport. A turntable is not a film.
- @likithareddy — Peggy. One phone, one sentence per beat. The soft gradient behind every shot is the default to resist.

## When the user supplies other references

Those become the primary brief. The fifteen above are background taste, not a look to impose on their product.

## Rule

Extract a few rules. Build an original system for the product in front of you. If the result is recognizable as one of these films with a different name, it is wrong.
