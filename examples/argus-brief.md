# Example creative brief: ARGUS

## Product thesis

Make the invisible failure in an agent workflow become visible, traceable, and fixable.

## Candidate narrative

1. Successful-looking agent run.
2. Tiny anomaly appears.
3. Execution trace expands.
4. One node becomes the causal center.
5. Argus names the silent failure.
6. User opens the relevant evidence/replay.
7. Fix lands.
8. Same path resolves cleanly.
9. Argus brand close.

## Visual motif

A single execution path / trace line that remains spatially coherent as the film moves from overview → node → evidence → fix → resolved state.

## UI strategy

Use real Argus UI for:

- execution trace
- root-cause/result evidence
- replay or diagnosis

Avoid showing the entire product dashboard unless it is legible at final size.

## Color strategy

Derive from actual Argus brand assets first. Use warning/critical colors semantically. Do not introduce unrelated neon palettes.

## Anti-patterns explicitly rejected

- repeating blurred orange background
- centered card for every scene
- tiny graph screenshot
- generic glow around all UI
- arbitrary camera rotation
- long logo reveal
