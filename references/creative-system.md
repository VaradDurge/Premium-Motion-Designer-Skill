# Creative system reference

## The quality hierarchy

1. Story clarity
2. Product truth
3. Composition
4. Typography
5. Motion
6. Sound
7. Finishing/effects

Never invert this hierarchy. Effects cannot rescue unclear product communication.

## Premium-feeling traits

- strong focal hierarchy
- confident negative space
- deliberate pacing
- restrained palette
- coherent type system
- motivated camera
- continuous spatial logic
- high-fidelity product UI
- selective detail
- small moments of surprise
- controlled imperfection only when intentionally art-directed

## Cheap-looking traits

- everything moves simultaneously
- every shot has the same layout
- every shot has a giant glow
- text is too small
- random gradients
- generic glassmorphism
- abrupt unrelated transitions
- effects used to hide weak design
- invented product UI
- too many ideas in too little time
